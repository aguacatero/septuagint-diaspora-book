# NAR — Narrative Generation Module

NAR asks what role Scripture played in producing a Gospel narrative.

It never assumes that literary dependence equals non-historicity.

## Competing causal models

1. **Historical event → scriptural interpretation** — an event or tradition existed independently and was subsequently described through scriptural language.
2. **Scripture → narrative generation** — the scriptural text materially generated the episode or its defining details.
3. **Mixed / co-constructed tradition** — some earlier tradition may exist, but Scripture substantially reshaped or generated major narrative particulars.

Each NAR record must state which models remain live and why.

## Evidence requirements

NAR analysis is downstream of TXT. It should consider textual specificity, sequence, density, authorial access, source dependence, independent attestation, and whether the historical-event model explains the details as well as or better than scriptural generation.

See `causal_ladder.md` for the classification ladder.
