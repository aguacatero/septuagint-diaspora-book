# CUL — Hellenistic / Greco-Roman Comparison Module

CUL asks how Gospel narratives relate to the wider Hellenistic and Greco-Roman literary environment after TXT and NAR analysis has been performed.

CUL does not treat resemblance as proof of copying.

## Classification vocabulary

1. **Direct dependence**
2. **Probable cultural influence**
3. **Shared Mediterranean convention**
4. **Weak parallel**

The term **borrowed** is reserved for the first two categories.

## Required controls

Every comparison must address the controls in `comparison_controls.md`.

A failed comparison remains visible as a rejected proposal where useful for auditability. Weak or failed parallels must not be rescued merely because they support a literary-origin thesis.
