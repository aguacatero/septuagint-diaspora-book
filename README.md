# Shaped by the Septuagint — A Book Project

This is a public-facing project working toward a peer-reviewed book.

**What it argues (short version)**
The New Testament — especially the books of Mark, Matthew, Luke, and John — was written in Greek and built on the Greek Septuagint (LXX), not on direct Hebrew sources. The authors lived in a Greek-speaking Jewish diaspora where the LXX was the working Scripture.

**What's included**
- A layered thesis (testable core + clearly marked speculative parts)
- Evidence for each chapter: proof, counter-argument, and response
- A 9-field claim-evidence matrix for every major claim
- Sources, outlines, and predictions that can be tested

**What's specifically NOT part of the core argument (bracketed / speculative)**
- The "Q" source is excluded from this project. It is not used as evidence.
- Mythic parallels (Osiris, Heracles, mystery cults) are labeled speculative and kept separate.
- Early non-canon gospels (Thomas, Peter, Mary) are included only as comparative notes, not as proof.
- The historical-Jesus question is bracketed — the book is about text and language, not historicity.

**Files in this repo**
- README.md — this file
- Core_Thesis.md — the core claim and rules
- Book_Scholar_Outline.md — 9-chapter outline with proof / counter / response
- Book_Part1.md through Book_Part4.md — chapter content (durable chunks, per-file commits)
- SOURCES.md — books, papers, and primary sources used
- docs/plans/ — design notes and research files

**How to read this**
Start with Core_Thesis.md for the claim, then Book_Scholar_Outline.md for the chapter plan. Each chapter has its own evidence rules (primary source, date, LXX vs MT comparison, counter, and falsifier — what would prove it wrong).

**Status**
Preliminary / work-in-progress. Nothing is final publication. All speculative claims are explicitly marked.
